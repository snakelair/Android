## 🕹️ Управление пультом Android TV

- **Стрелки (D-pad Up/Down/Left/Right):** Навигация между вариантами (A, B, C, D) и меню.
- **Центральная кнопка (OK / D-pad Center):** Выбор ответа / Старт / Пауза.
- **Кнопка «Назад» (Back):** Выход в меню или отмена.
