# 🎤 АПОЖ (Песня наоборот / SingItBack) — Android & Android TV

Легендарная музыкальная игра-викторина **«АПОЖ» (Песня наоборот)** для больших экранов **Android TV / Google TV**, а также планшетов и смартфонов.

---

## 🎮 Правила и геймплей

1. **Разбиение на фрагменты**: Песня разрезается на 3–6 смысловых частей (фраз).
2. **Реверсивное прослушивание**: Каждый фрагмент проигрывается задом наперёд с возможностью повтора.
3. **Запись голоса**: Игрок нажимает запись и максимально точно повторяет услышанную абракадабру.
4. **Магия реверса**: После записи всех частей приложение мгновенно:
   - Переворачивает записанные дорожки обратно;
   - Выравнивает громкость с помощью LUFS/RMS нормализации;
   - Склеивает их в правильной прямой последовательности.
5. **Трехуровневая система угадывания**:
   - 🎯 **3 балла** — Угадать песню сразу по записанному треку без подсказок!
   - ✨ **2 балла (Подсказка 1)** — Включить автотюн и выравнивание записи по нотам оригинальной песни (YIN Pitch Detection + PSOLA pitch shift).
   - 📋 **1 балл (Подсказка 2)** — Открыть 4 варианта ответа.
6. **Финальный показ**: Воспроизведение оригинального видеоклипа в HD 720p с наложением и микшированием вокала игрока.

---

## 📲 Спаривание со смартфоном (Companion Mode)

- **TV Режим**: Запуск на телевизоре отображает 4-значный PIN и поднимает локальный NSD/mDNS сервис и UDP Broadcast.
- **Телефон как микрофон и пульт**: Смартфон подключается в 1 клик и может использоваться как беспроводной студийный микрофон и пульт управления.

---

## 🛠 Веб-редактор каталога песен

В проект встроен веб-редактор каталога песен аналогичный «Стоп-Кадру»:
- Локальный HTTP сервер на порту 38090 (python tools/editor_server.py);
- Визуальный редактор волны трека, разметка таймкодов 3–6 частей, тест реверса каждого фрагмента;
- Назначение вариантов ответа и нот мелодии;
- Модерация и аппрув (isApproved: true/false);
- Единый JSON файл database/songs_db.json.
